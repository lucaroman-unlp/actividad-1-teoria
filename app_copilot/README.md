# Galería de Dibujos - Luca Roman

## Descripción
Sitio web estático para publicar dibujos en diferentes categorías. Completamente responsivo y sin JavaScript.

## Estructura de archivos
```
app_copilot/
├── index.html           # Página principal (única página HTML)
├── estilosIA.css        # Archivo de estilos
└── imagenes/            # Carpeta de imágenes
    ├── caricatura1.png
    ├── caricatura2.png
    ├── paisaje1.png
    ├── paisaje2.png
    ├── anime1.png
    └── anime2.png
```

## Instrucciones de uso

### 1. Cargar imágenes
Coloca tus imágenes PNG en la carpeta `imagenes/` con los siguientes nombres:
- **Caricaturas**: `caricatura1.png`, `caricatura2.png`
- **Paisajes**: `paisaje1.png`, `paisaje2.png`
- **Anime**: `anime1.png`, `anime2.png`

### 2. Abrir el sitio
Abre el archivo `index.html` en tu navegador web.

## Características

✅ **Navegación intuitiva** - Barra de navegación fija con enlaces a todas las secciones
✅ **Dropdown de categorías** - Menú desplegable con las 3 categorías de dibujos (sin JavaScript)
✅ **Galería responsiva** - Las imágenes se adaptan a cualquier dispositivo
✅ **Formulario de contacto** - Formulario simple con campos de nombre, apellido, email y teléfono
✅ **Sección Acerca de** - Información sobre Luca Roman
✅ **Diseño armónico** - Todos los dibujos tienen bordes y relleno uniforme
✅ **CSS moderno** - Gradientes, sombras y transiciones suaves
✅ **Completamente estático** - Sin scripts, puro HTML y CSS
✅ **Mobile-first** - Optimizado para dispositivos móviles, tablets y desktops

## Secciones

1. **Inicio** - Página de bienvenida con descripción general
2. **Caricaturas** - Galería de caricaturas (2 imágenes)
3. **Paisajes** - Galería de paisajes (2 imágenes)
4. **Anime** - Galería de anime (2 imágenes)
5. **Contacto** - Formulario de contacto simple
6. **Acerca de** - Información del autor

## Puntos de personalización

Si deseas modificar algo, edita el archivo según sea necesario:

- **Nombres de imágenes**: Edita las rutas en `index.html`
- **Colores**: Modifica los valores en `estilosIA.css` (busca variables de color)
- **Textos**: Actualiza el contenido en `index.html`
- **Información del autor**: Modifica la sección `<section id="autor">` en `index.html`

## Navegación por teclado

El sitio es completamente accesible:
- Usa **Tab** para navegar entre elementos
- Usa **Enter** para activar enlaces
- El navegador proporciona navegación fluida con desplazamiento suave
